The solver minimises total sailing distance: every straight-line leg from one foundation to the next, including the leg that joins one trip to the next. Harbour transit is not included. Choose one location or an attribute. The number is the first trip those locations may be installed. Enter 2 to keep them out of the first trip. For a Yes/No column such as Shallow location, use equals and YES.
{% endif %} {% if constraint_type == "loop_id_sequence" %}
Cables that share a Loop ID follow the IAC sheet, one after another, and stay inside one trip. A hard rule that installs some of them first takes those cables out. The cables that remain stay one uninterrupted block. A different Loop ID may come before or after that block. A blank Loop ID is not grouped. A hard rule that cannot be met makes the run invalid. A soft rule penalises a break and keeps the run valid.
{% endif %} {% if constraint_type == "package_buffer" %}
IAC waits for the FOU end at the same location. WTG waits until every cable that touches that location is complete. IAC starts at a location when the first of those cables starts. The gap uses the programme P50 dates of each sequence slot. A location missing from the previous package is left out. Maximize has no day limit. A hard minimum must be met. A soft minimum penalises the shortfall by severity.
{% endif %}
